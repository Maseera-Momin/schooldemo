# SCHOOL WEBSITE — PRODUCT REQUIREMENTS DOCUMENT (PRD)

## 1. Project Overview

Create a **professional, modern, responsive school website** using React.

The website should feel like it was designed and developed by a **real professional web designer/developer**, not generated by AI.

The design should be:

* Clean
* Trustworthy
* Warm
* Educational
* Professional
* Easy for parents, students and visitors to use
* Visually interesting without excessive animation
* Responsive on mobile, tablet and desktop
* Fast and accessible

The website should use:

* React
* Vite
* GSAP
* GSAP ScrollTrigger
* React Bits components
* HTML5
* CSS3
* JavaScript/TypeScript
* Google Fonts or another appropriate free font source

Do NOT make the website look like a generic SaaS/AI landing page.

---

# 2. Design Philosophy

The website should communicate:

> "A trustworthy school with strong academics, caring teachers and a welcoming environment."

Avoid:

* Excessive gradients
* Neon colors
* AI-generated-looking copy
* Huge futuristic text
* Excessive glassmorphism
* Excessive 3D effects
* Random floating objects
* Overuse of rounded cards
* Excessive animations
* Generic AI phrases such as "Unlock your potential with our innovative ecosystem"

Instead use:

* Realistic school imagery
* Strong typography
* White/cream backgrounds
* School-color accents
* Simple cards
* Editorial layouts
* Image-and-text sections
* Proper spacing
* Subtle borders
* Small shadows
* Human-written copy
* Practical navigation
* Purposeful animations

320–767px

Large navigation.

# 31. Accessibility

Implement:

* Semantic HTML
* Proper heading hierarchy
* Alt text
* Keyboard navigation
* Visible focus states
* Accessible buttons
* Accessible forms
* Sufficient color contrast
* Reduced-motion support

Respect:

`prefers-reduced-motion`

If the user disables animations, reduce or remove non-essential animations.

---

# 32. Performance

The website should remain lightweight.

Requirements:

* Lazy-load images
* Compress images
* Use modern image formats when possible
* Avoid unnecessary JavaScript
* Avoid excessive WebGL
* Avoid huge animation libraries beyond required components
* Animate transform/opacity where possible
* Avoid layout-heavy animations
* Use React component reuse

Target:

Smooth scrolling and responsive interaction on normal laptops and mobile phones.

# 36. Human-Generated Content Rules

All website copy should sound like it was written by a real school.

DO:

"Every student deserves a place where they can ask questions, make mistakes and grow with confidence."

DON'T:

"Unlock an innovative educational ecosystem designed to empower the next generation."

DO:

"Our teachers work closely with students and families to create a supportive learning environment."

DON'T:

"Experience a transformative, next-generation learning journey."

Content should be:

* Specific
* Warm
* Simple
* Natural
* Informative
* School-focused

Avoid generic AI marketing language.

# 45. Animation Performance Rules

Never animate:

* Large numbers of DOM elements simultaneously
* Heavy blur effects continuously
* Huge WebGL scenes
* Excessive 3D elements

Prefer:

```text
transform
opacity
scale
x
y
clip-path
```

Use `will-change` only where justified.

Kill GSAP animations/ScrollTriggers when components unmount.

# 47. Final Visual Direction

The final website should feel like:

**A premium private/public school website designed by an experienced human designer.**

Visual keywords:

**Warm + Professional + Educational + Modern + Trustworthy + Clean**

Not:

**AI + Futuristic + SaaS + Overanimated + Neon**

The design should prioritize **content, photography, typography and usability**, with GSAP and React Bits providing subtle polish rather than becoming the main attraction.

---

# 48. Definition of Done

The project is complete when:

1. All primary pages are implemented.
2. Navigation works across desktop and mobile.
3. All major sections are responsive.
4. GSAP ScrollTrigger animations are implemented.
5. React Bits components are integrated selectively.
6. Website copy feels human-written.
7. School imagery is consistent.
8. Contact/admission forms have validation.
9. Gallery/lightbox works.
10. Events and notices are structured.
11. Mobile menu works correctly.
12. Accessibility basics are implemented.
13. SEO metadata is implemented.
14. No horizontal scrolling exists on mobile.
15. Animations do not cause noticeable lag.
16. The website looks professional without looking AI-generated.
17. Code is organized into reusable React components.
18. The final website is ready for deployment.

## Core Principle

**Build a school website first, and an animated website second.**

Every animation, React Bits component and visual effect must have a reason to exist. If removing an animation makes the website easier to use, remove it.
